The whole session was chasing a week-old bug: tapping a monument on the Capacitor globe either did nothing or crashed the WKWebView, then bypass-mode stranded the user on a static planet. Sentry pattern: `webview_respawn` in phase `capacitor-globe:monuments-glb-load` or `shop:<mk>:opened`. Fixed incrementally through the day; final state has three parallel escape hatches so users can always reach their collection.

### What's live now (`5fc1e5f`)

- **Marker tap** — 140x140 transparent div at each monument's lat/lon, single click handler, sync `globe-pause` + `jumpTo` + dispatch shop. Scale-down visual on pointerdown, restored on pointerup.

- **Sync pause guarantee** — every path that opens the shop (marker tap, name-pill tap, deep-link) goes through AtlasShell's `open-monument-shop` handler which dispatches `geknee:globe-pause` synchronously before `setShopOpen(true)`. On native the MonumentShop skips its post-mount `flyGlobeTo` so it can't revive the paused GL.
