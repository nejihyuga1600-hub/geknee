## Critical Anti-Patterns (do NOT repeat these)

| Pattern | Description | Severity | Prevention |
|---|---|---|---|
| Launch CDP Chrome against the user's default profile | Recent Chrome silently disables `--remote-debugging-port` on the default profile (anti-credential-theft policy). Will appear to launch but CDP never binds, no `DevToolsActivePort` file. | blocking | `launch-chrome.sh` already points at `~/.gekneetravel-chrome-data`. Do not revert. |
| Try to drive a native macOS file picker via CDP/browser-use | `NSOpenPanel` is OS-level, not DOM. Wastes agent steps. | blocking | Either AppleScript-drive (Cmd+Shift+G) OR refactor `post.py` to find the hidden `<input type="file">` and use `setInputFiles` directly via CDP. |
| Run `post.py` while the user is also clicking manually in the same Chrome | Race conditions; agent gets confused; either flow can fail mid-step. | advisory | If user takes manual control, `TaskStop` the post.py background task. |
| Commit the user's `.env` files | Tokens/keys would leak to git history. | blocking | `.gitignore` in `~/geknee/.agents/ig-poster/` and `~/geknee/.agents/mcp-meta/` already excludes `.env`. Verify before any `git add`. |
| Force-kill the user's Chrome to "make CDP work" | Destroys their unrelated tabs/work. | blocking | Ask first; or use a dedicated profile so the default Chrome can keep running. |
| Generate ads with Higgsfield video without preflighting cost | User is on free plan (10 credits). Seedance 2.0 = 22.5 credits. Will fail/exceed budget. | advisory | Always `get_cost: true` before submitting. |
| Post identical captions across days | IG and Andromeda penalize repetition. | advisory | Skill must read `captions.md` and rotate V1→V2→V3 per audience based on `.last-posted.json`. |
