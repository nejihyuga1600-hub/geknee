# GeKnee — IG caption pool

3 variants per audience. The `/geknee-daily-ad` skill picks the least-recently-used variant for the chosen audience (track via `~/geknee/ad-assets/.last-posted.json` — store the variant index alongside the date).

Voice: cosmic-editorial. Specific over generic. No emoji except the ✦ glyph (use sparingly — at most once per caption). Hashtag rule: 5–7 tags per post, audience-targeted, never the same stack twice in a row.
